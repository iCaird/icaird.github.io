I recently stumbled across [this] github repo. The goal of the project is to decompile the
Playstation (PSX) game "Spyro: Year of the Dragon", i.e. produce code that can be compiled
into a binary file that perfectly matches the game. This is about as much as I understood about
decompilation back then. This game is the earliest I can remember playing as a child and
consequently I wanted to figure out what was going on and how I might be able to
help. I still don't know a whole lot, but this page will serve to help me (and any readers) to
understand better through documenting!
